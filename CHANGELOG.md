# Changelog

## v1.2.1 — GitHub-ready modular package
- Memisahkan CSS ke `styles.css` dan JavaScript ke `app.js` agar lebih mudah dirawat.
- Menambahkan CSS dan JavaScript ke cache service worker untuk dukungan offline.
- Menyiapkan seluruh file langsung di root agar mudah diunggah ke GitHub Pages.
- Menambahkan panduan GitHub berbahasa Indonesia.
